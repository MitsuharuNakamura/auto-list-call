
# Twilio 自動架電アプリ

Node.js と Twilio を利用し、CSV リストに自動で架電を行うシングルページ Web アプリケーションです。

## 主な機能

- CSV ファイルから架電リストを読み込み（名前, 電話番号）
- 読み込み時にフォーマットチェック（カンマ区切りでない場合はエラー表示）
- 読み込んだリストをテーブル表示し、各通話ステータスを表示
- メッセージ内容の設定（言語と音声を選択可能）
- 自動架電を実行し、順次通話を実施
- 通話結果に応じてステータスを「OK」「NG」で表示
- 画面上部に全体の進捗状況を表示
- 全通話完了後に完了メッセージを表示

## 必要条件

- Node.js (v14 以上推奨)
- npm
- Twilio アカウント

## 環境構築

1. レポジトリをクローン  
   ```bash
   git clone <REPO_URL>
   ```
2. `.env.example` をコピーして `.env` を作成  
   ```bash
   cp .env.example .env
   ```
3. `.env` に以下の値を設定  
   ```dotenv
   TWILIO_ACCOUNT_SID=your_account_sid
   TWILIO_AUTH_TOKEN=your_auth_token
   TWILIO_PHONE_NUMBER=+1234567890
   ```
4. 依存パッケージをインストール  
   ```bash
   npm install
   ```

## 起動方法

```bash
npm start
```

ブラウザで `http://localhost:3000` にアクセスしてください。

## CSV サンプル

以下のような形式の CSV ファイルを使用します（ヘッダー行不要）:

```
山田太郎,+819012345678
鈴木花子,09012345679
```

プロジェクトには `sample_list.csv` としてサンプルファイルを同梱しています。

## 使い方

1. 「ファイルを選択」ボタンから CSV ファイルをアップロード
2. 架電リストと進捗状況が画面に表示される
3. 言語・音声を選択し、流すメッセージを設定
4. 「自動架電開始」ボタンをクリック
5. 通話が完了するごとにステータスが更新され、すべて完了すると完了メッセージが表示される

## 注意事項

- 各行は「名前,電話番号」の形式で記載してください。
- 電話番号は国際形式（先頭に "+" と国番号）または国内形式（0 から始まる番号）で入力してください。
